# Format: how-to

Built to teach one job, end to end, with real screen recordings. Paired with an explainer on the same topic.

## Shape (3 to 5 minutes)

| Beat | Job |
| --- | --- |
| Outcome | The result the viewer wants, and why it usually goes wrong |
| First principles | How the underlying thing works (for AI: what it learned in training versus what you give it) |
| Method | The framework: what to give, what to leave out, which input shapes which output |
| Set it up | Real recordings of the product, each section named as it's shown |
| Test and refine | Run it, read it, fix the rule rather than the output, run it again |
| Key takeaways | Three bullets, also in the description |
| CTA | The free toolkit, with its link on screen, plus a card for the other toolkits |
| Sources card, logo close | As in the explainer |

## Teaching layer (on screen)

- Chapter labels for each section, and an agenda card at the start.
- A takeaway card at the end of each section.
- Bullet tables and checklists that build as they are spoken.
- Numbered steps for anything the viewer should repeat.
- Pro-tip and note cards for the one thing people get wrong.
- Copy rules: short, no dashes, no claims beyond the claims check.

## Recordings

Real product, real output, on a fictional demo brand only. Record the full UI without zoom or annotations; the edit adds zooms, rings and labels from an events file. See `video/capture/` for a complete brief.

Worked example: `video/examples/mavic/ep1b/`.
